星屑圣诞树 · 使用与拆解

观看与操作
在解压目录用新版 Edge 或 Chrome 打开「打开圣诞树.html」。树上预装了本次分享的 19 张照片，网页已内置字体、手势模型和运行引擎。点击「开启手势」并允许摄像头，将一只手放进左下角的预览。
如果预览全黑，在下拉框中选择普通彩色摄像头，检查镜头滑盖和光线，再点「重连」。需要检查镜头时，先关闭网页手势，再用 Windows「相机」试拍。

张开手掌让星光散开，横移手掌调整角度。把屏幕上的圆形指针对准想看的相框，捏合拇指和食指，让照片来到中央。松开手指可回到星空，握拳让粒子重新聚成树。食指与中指比 V，保持约 0.6 秒即可切换一种灯色。放下手后再次比 V 可以继续切换。

没有摄像头时，点击「散开星光」，拖动旋转，再点相框。键盘空格可切换聚散，左右方向键旋转或翻照片，Esc 返回。左下角可直接选择鎏金、冰蓝或玫瑰。

在本机增删照片
打开「相册」，可以预览、导入或移除照片，支持浏览器能读取的图像格式。最多可挂 24 张，移除最后一张个人照片后，树上会显示六张冬日明信片。后续改动存入这台电脑当前浏览器的 IndexedDB。浏览器禁用存储时，改动仅在本次打开期间有效。

参考视频里的变化
开头约 0–3 秒，树形保持聚拢，灯光出现暖金、冰蓝和粉色。约 4–9 秒，粒子和金边照片向外飞散。约 10–13 秒及 24–27 秒，镜头前出现捏合动作，一张照片移到中央放大。张手后画面又回到散开的相册。本版用握拳作为归树动作，用 V 手势轮换颜色。

本版的实现
1. 为每个光点准备两组位置
dist/scene.js 生成多层向外伸展的树枝，再将两股螺旋灯带、金属挂球和树顶星加上去。每颗粒子还有一组随机星空坐标。setSpread 改变目标状态，draw 每帧更新过渡量。project 对坐标做旋转和透视投影，再由 Canvas 2D 画出。前后光点的亮度与大小不同，因此树能真正转动。

2. 从摄像头读取手势
dist/gestures.js 的 HandControl 在用户授权后取得视频流，交给 MediaPipe Hand Landmarker。模型输出每只手的 21 个关键点。classify 以掌宽和掌长定标，通过指尖距离和指节弯曲判断姿势，适配左右手及不同拍摄距离。
捏合使用拇指尖 4 和食指尖 8。同时测量模型给出的三维距离和画面上可见的二维距离，用相应的手掌尺寸定标。综合距离小于 0.31 可以进入捏合，保持时放宽至 0.44，这样侧着手捏合也容易识别。PoseLatch 还要求手势短暂停稳。例如捏合约 145 毫秒，换色约 620 毫秒，可减少边界抖动。可在这里调整灵敏度和停留时间。

3. 把指尖和照片连起来
dist/app.js 将镜像后的食指坐标映射到屏幕，TreeScene.nearest 按屏幕距离挑出最近的相框。进入捏合时，app.js 从相框当前位置发起放大动画。松开后关闭预览，保持之前的星空视角。鼠标和触屏与手势共用同一套场景和照片。

4. 调整画面和相册
修改 dist/scene.js 的 palettes 可以调整三套光色。修改 dist/style.css 可调整标题、按钮和胶片边框。dist/album.js 负责导入、缩图、保存以及六张示例图的名称。示例图片位于 dist/assets/winter-1.jpg 至 winter-6.jpg。模型和 WebAssembly 文件位于 dist/vision。

编辑要随作品分享的照片
打开 dist/photos/album.json。每一项的 file 是同一文件夹里的 JPEG 文件名，name 是相框标题，id 是这张照片的唯一编号。列表中的先后就是树上的相册顺序。
可以用新的 JPEG 替换同名文件，或把 JPEG 放入 dist/photos 后在清单里新增一项。为新照片取一个从未用过的 id，例如 photo-20。若要移除一张，就删掉对应项。清单最多保留 24 项。

预览可编辑源码
在解压后的项目根目录打开终端。装有 Python 3.8 或更新版本的电脑可执行下列命令，再用浏览器打开 http://127.0.0.1:8000/ 。按 Ctrl + C 停止本机服务。

python -m http.server 8000 --bind 127.0.0.1 --directory dist

从源码重新生成单文件
在同一目录执行以下命令。打包脚本使用 Python 标准库。它读取相册清单与对应 JPEG，把网页、照片、字体、手势引擎和模型嵌进根目录的「打开圣诞树.html」。把新文件发给朋友，对方就能看到修改后的相册。
